# 电商价格策略与销量预测 - 核心结论

## 一、数据规模
- 50个SKU，全年366天，18,300条销售记录
- 覆盖女装、鞋包、配饰3个品类，含成本、竞品价、库存、折扣

## 二、分析方法
1. **价格弹性**：双对数OLS回归 log(销量) ~ log(价格) + 折扣 + 竞品价
2. **销量预测**：随机森林，R²=0.957，MAPE=17.6%
3. **利润优化**：基于预测模型网格搜索最优价格点

## 三、核心发现
1. **整体价格弹性 = -1.787**，用户对价格高度敏感（R²=0.971）
2. 价格是销量的第一驱动因子（特征重要性98.1%）
3. 竞品价格显著影响销量（p<0.001），但影响幅度远小于自身价格
4. 折扣对销量的边际贡献为负（-0.081），说明折扣更多是走量而非提效
5. 通过利润最优化，部分SKU存在2.5%~31.8%的利润提升空间

## 四、分品类价格弹性
| 品类 | 弹性 | R² | 平均售价 | 平均毛利率 |
|------|------|-----|---------|-----------|
| 配饰 | -1.802 | 0.966 | 242.6 | 47.7% |
| 女装 | -1.781 | 0.972 | 275.6 | 48.9% |
| 鞋包 | -1.760 | 0.974 | 295.2 | 50.5% |

**结论**：三大品类弹性均低于-1.75，属于高度价格敏感型。

## 五、业务建议
| 品类 | 建议策略 | 具体动作 |
|------|---------|---------|
| 配饰 | 渗透定价 | 降价3-5%，主推爆款 |
| 女装 | 渗透定价 | 降价3-5%，测试效果 |
| 鞋包 | 渗透定价 | 降价3-5%，配合活动 |

**核心策略**：统一采取渗透定价，小幅降价撬动销量，以量补价。

## 六、利润优化示例
| SKU | 当前利润 | 最优利润 | 提升幅度 |
|-----|---------|---------|---------|
| SKU001 | 715 | 752 | +5.1% |
| SKU010 | 1280 | 1312 | +2.5% |
| SKU020 | 620 | 818 | **+31.8%** |
| SKU030 | 1350 | 1453 | +7.6% |

> SKU020 存在明显定价偏离，建议优先执行调价。

## 七、落地动作
1. 对弹性最高的SKU，尝试降价3-5%，观察7天销量
2. 建立价格监控看板，价差>10%时触发预警
3. 高库存SKU优先执行渗透降价，加速周转
4. 每2周复盘一次弹性变化，动态调整定价
